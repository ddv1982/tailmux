Tailmux 0.2.0 installs a standalone local client and resumes tmux sessions through Tailscale SSH.

- Add a no-checkout macOS and Linux installer with authenticated, source-pinned release assets.
- Verify the installer before execution and the canonical package before installation.
- Preserve operator-owned dependencies, shell configuration, and destination setup.
- Add dependency diagnostics, strict peer selection, and one fail-closed Tailscale SSH transport.
- Keep installation receipts, same-version retries, and owned-file uninstall support.

See the README for installation and `docs/releases.md` for publisher verification.
